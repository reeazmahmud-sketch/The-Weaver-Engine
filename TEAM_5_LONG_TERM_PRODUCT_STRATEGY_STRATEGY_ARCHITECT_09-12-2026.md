## 1. Mission

| Input | Process | Output |
|-------|---------|--------|
| Market / competitor / research signals | Strategy analysis | Ranked feature / pivot / retirement options |
| Metric Sentinel trends | Value honesty check | Kill vanity roadmap items lacking value proof |
| Evolutionary Learner explorations | Commercial prioritization | Ordered CEO brief |
| CEO priorities / ethics constraints | Human partnership | Accepted / rejected / deferred strategy moves |

### 1.1 Explicit non-goals

* Do **not** silently set company direction.  
* Do **not** own technical Go/No-Go (Team 4).  
* Do **not** implement modules (Team 2) or hotfixes (Team 3).  
* Do **not** treat a single “recommended” option as a decision without CEO gate.  
* Do **not** claim Strategy Architect is coded in Weaver.

## 2. Long-term product strategy responsibilities

| Responsibility | Detail |
|----------------|--------|
| **Roadmap honesty** | Features must survive Metric Sentinel + market evidence, not internal wish lists |
| **Pivot / retirement options** | Explicitly recommend stop / shrink / replace when value or market fails |
| **Modular blast radius** | Prefer MCP/hook/skill/extension-shaped changes over monolith bets |
| **Enterprise 2026 stance** | Agents as mainstream ops → continuous reinvention with humans central |
| **CEO briefing** | Options + trade-offs + evidence; investment priority stays with CEO |
